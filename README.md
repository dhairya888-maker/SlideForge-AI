# SlideForge AI

### AI-powered Social Media Studio for Parents

SlideForge AI transforms raw ideas into polished, visually rich, ready-to-post educational creatives.

It blends AI + storytelling + design to produce content that is clear, engaging, and immediately usable.

**Live Frontend:** [slide-forge-ai-xi.vercel.app](https://slide-forge-ai-xi.vercel.app/)  
**Live Backend:** [slideforge-ai.onrender.com](https://slideforge-ai.onrender.com)

---

## ✨ Why SlideForge AI

SlideForge AI is built for fast idea-to-output workflows.

Instead of writing and designing from scratch, parents can turn one rough thought into structured social content in seconds.

---

## 🚀 Features

- 🧠 Idea → content transformation
- 🎨 Content-aware visuals
- 📱 Multiple formats: Post, Story, Carousel
- 🧩 Dynamic templates (no fixed layouts)
- 🌗 Dark & Light mode
- 🎨 Custom color themes
- 🖼 AI-generated backgrounds
- 📥 Download-ready slides (single + ZIP)

---

## 🧠 How It Works

1. User enters a rough idea.
2. AI structures it into a storytelling format.
3. Slides are generated dynamically by format and slide count.
4. Visuals adapt to the topic and design style.
5. User downloads ready-to-post content.

---

## 🎨 Design Philosophy

- **Storytelling-first**: content flows logically, not randomly.
- **Content-aware system**: visuals and layout adapt to meaning.
- **Clean UI**: minimal interface, premium visual language.
- **Readability-focused**: clarity over clutter, always.

## 🛠 Tech Stack

### Frontend

### Backend

- Express

### AI
- OpenRouter API

### Deployment
- Vercel + Render

---

## ⚖️ Key Decisions

- Reduced friction from idea to output.
- Used structured storytelling instead of plain text dumping.
- Built adaptive design logic instead of static templates.

---

## ⚠️ Trade-offs

- Skipped authentication to iterate faster on core UX.
- Prioritized core creation flow over secondary features.
